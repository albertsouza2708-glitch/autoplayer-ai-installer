## Recursos atuais

- Painel flutuante com leitura do estado do personagem.
- Seguir a missão que já estiver ativa, usando `irParaMissao()` do jogo.
- Combate por turnos: usa a primeira habilidade disponível; se não houver, tenta defender.
- Botão para interromper todas as automações.

## Limitações desta versão

- Não aceita/inicia missões automaticamente.
- Não automatiza coleta, diárias, eventos, exploração ou Raid.
- Ainda precisa de teste dentro do jogo; a publicação e a leitura de volta do arquivo no GitHub foram verificadas, mas não houve teste de execução no navegador.
